# Roadmap

Each milestone is one worktree (`~/Projects/code-atlas-wt/<task>`, branch `<task>`), merged into `main`.
Own new files freely; touch `app.rs` / `ui.rs` / `main.rs` only with small hooks, and rebase on `main` before merging.
